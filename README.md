### 📊 Dataset Source: Multiple Google Trends APIs (Country Wise, Date Wise, Related Keywords)  
---

## 📘 Introduction

The **Dynamic Google Trends Dashboard** is a Power BI project that transforms **raw search interest data** about global **job-related concerns**—such as “gender pay gap,” “job stress,” and “work-life balance”—into **interactive business intelligence**.  

Designed with **dynamic functionality**, this dashboard allows users to **instantly switch between different job concern topics**, automatically updating every visual across all pages. Through powerful integrations with multiple Google Trends APIs, it delivers **geographic**, **temporal**, and **contextual** insights into public sentiment surrounding workplace issues.

---

## 🎯 Objectives

1. **Visualize geographic interest** for each concern (e.g., percentage of searches for *“work-life balance”* by country).  
2. **Enable dynamic topic switching** using Power BI parameters—change the focus from *“gender pay gap”* to *“employee discrimination”* in one click.  
3. **Analyze temporal evolution** of job concerns using a dynamic **date-axis slicer** (Year, Quarter, or Month view).  
4. **Identify related and rising search terms** using keyword API feeds for contextual understanding.  

---

## 💡 Why This Approach?

| Feature | Description |
|----------|-------------|
| **Dynamic Input Control** | Uses an external keyword parameter, allowing users to switch job concern topics instantly without editing queries. |
| **Dimensional Data Breakdown** | Combines multiple APIs for Country-wise, Date-wise, and Related Keyword data, offering 360° analysis. |
| **Visual Clarity** | Custom backgrounds (from Figma or Pia Pa) and synchronized colors improve readability and visual appeal. |
| **Actionable Intelligence** | Identifies regional hotspots and rising keyword trends for more informed strategic analysis. |

## 🚀 Project Deliverables

| Deliverable | Description |
|--------------|-------------|
| **Data Cleaning & Transformation** | Converted country percentages to decimals, handled string–numeric errors, and unified Rising/Top keyword tables. |
| **Dynamic Parameters** | Created Power BI parameters for **keywords** and **date axis** switching (Year, Quarter, Month). |
| **Visualizations & Interactivity** | Added a **custom map**, **flag slicer** (via image URLs), and **dynamic titles** that update with the selected concern. |
| **Utility & Reporting** | Included a calculated table for **Last Refresh Date** and formatted keyword columns as **clickable web URLs**. |
